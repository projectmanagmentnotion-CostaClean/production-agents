# Enterprise Agent Pack

Para diseñar el software de agentes empresariales que se ejecutarán en backend, workers o funciones controladas.

## Base

- `implementation-planner`
- `senior-fullstack-builder`
- `qa-e2e-specialist`
- `security-privacy-auditor`
- `business-rules-test-engineer`
- `enterprise-agent-architect`
- `pr-quality-gate`

## Principios

- El agente empresarial real no vive únicamente en GitHub Agents.
- GitHub almacena código, reglas, herramientas, evaluaciones y documentación.
- Acciones externas sensibles requieren aprobación humana.
- La IA no recibe SQL libre ni credenciales generales.
- Cada empresa queda aislada por tenant, permisos y datos.
- Todo flujo debe ser idempotente, auditable y reversible.

## Primer piloto recomendado

Costa Clean: nuevo lead → validación → cálculo determinista → presupuesto borrador → aprobación humana → email → seguimiento.
