# GSAP Web Pack

Para webs visuales, landings y experiencias inmersivas con GSAP, ScrollTrigger, imágenes y vídeo.

## Base

Instala todo `packs/universal`.

## Especialistas

- `frontend-ux-accessibility`
- `performance-gsap-motion`
- `seo-local-structured-data`
- `release-deployment-guardian`

## Gates

1. Implementación visual.
2. Responsive y accesibilidad.
3. Rendimiento y movimiento reducido.
4. SEO técnico y local.
5. Preparación de artefacto, smoke y rollback.
6. Revisión humana antes de producción.

No se acepta una experiencia visual que bloquee navegación, formularios, contenido indexable o usuarios con movimiento reducido.
